Filled by the team; agents read context from here, not from chat history.

| `superpowers/plans/` | Architect | one plan per milestone: contracts, tests, traceability |
| `architecture/` | Architect | ARCHITECTURE.md, adr/, TECH-DEBT.md |
| `design/` | Designer | design-system/<slug>/MASTER.md, tokens.css, screens/, prototypes/, reviews/ |
| `tasks/` | board.py only | milestones, stories, tasks, bugs; BOARD.md is generated |
| `qa/` | QA | TEST-STRATEGY.md, plans/, reports/, evidence/ |
| `security/` | Security | scope.md, <M>-security.md |
| `solutions/` | whoever fixed it | non-obvious problems and their fixes (grep before debugging) |
